## O que foi feito

### Main
- **`src/main/ai/compact.js`** (novo)
  - `estimateTokens(messages)` — caracteres ÷ 4 de texto, partes de texto, argumentos de tool
    calls e saídas de ferramenta; imagem conta fixo (~1000 tokens).
  - `compactToolOutputs(messages, { keep = 10 })` — troca o conteúdo das saídas de ferramenta
    antigas (todas menos as últimas 10) por `[saída compactada: <primeira linha>… (N caracteres)]`.
    Não remove nem reordena mensagens (pares tool_call/tool_result intactos para OpenAI e
    Anthropic), não muta a entrada, é idempotente e só troca quando o marcador é menor.
  - `buildSummaryMessages(messages)` + `SUMMARY_PROMPT` (pt-BR): seções Objetivo, Decisões,
    Arquivos alterados (caminho — o quê), Estado atual, Pendências e próximos passos, Trechos
    essenciais (erros, comandos); conciso, sem segredos, sem continuar a tarefa.
- **`ipc/ai.js`** — `ai:summarize(requestId, { profileId, model, messages })` →
  `{ ok: true, summary } | { ok: false, error, cancelled? }`. Usa o mesmo perfil/modelo da
  conversa, expande anexos como o chat (`prepareMessages`), nunca lança. `ai:cancel` também
  aborta um resumo em andamento. Preload: `window.agzos.ai.summarize`.
- **Laço do agente (`agent/loop.js`)** — novo parâmetro `compactThreshold`. Antes de cada
  chamada ao modelo, se `estimateTokens(messages)` passar do limite, aplica
  `compactToolOutputs` e emite `{ type: 'compacted', removedChars }`. `session.js` recebe
  `getCompactThreshold()`; `ipc/agent.js` passa `aiPanel.compactThresholdTokens` quando
  `aiPanel.autoCompact` está ligado (desligado → 0, sem compactação no laço).
- **Settings (`lib/settings.js`)** — `aiPanel.autoCompact: true`, `aiPanel.compactThresholdTokens:
  60000` (normalizado para 8000–400000; string numérica do campo vira número).
- **Histórico (`ipc/chat-history.js`)** — mensagem de resumo
  `{ role: 'assistant', kind: 'summary', content, compactedCount, createdAt }` é preservada;
  `kind` só vale em `assistant`; histórico antigo sem resumo carrega igual.
- **Export (`chat-export.js`)** — o resumo vira `## Conversa compactada — N mensagens
  resumidas` com o texto (títulos internos descem um nível), entre as mensagens antigas e as
  novas. As mensagens antigas continuam no Markdown/PDF.

### Renderer
- **`ai-chat-utils.js`** — `estimateTokens` (texto sem o marcador do agente + anexos: texto pelo
  tamanho, PDF por ¼ do tamanho, imagem fixo), `modelMessages` (sem resumo → tudo; com resumo →
  último resumo como mensagem `user` com `SUMMARY_PREFIX` + posteriores), `compactableMessages`,
  `compactedBefore`, `makeSummaryMessage`, `isSummary`. Redutor: evento `compacted` vira o
  segmento `{ t: 'compacted', removedChars }` (preservado por `compactAgentTurn`).
- **`ai-chat.js`**
  - `compactConversation({ auto })` (exportada): resume o último resumo + as mensagens
    posteriores com o modelo atual; enquanto isso `request = { compact: true }` (botão vira
    Parar, Enter enfileira) e aparece "Compactando conversa…". Sucesso → mensagem de resumo no
    fim da conversa e `persist()`. Falha → `#ai-error` com a mensagem do provedor, conversa
    intacta. Menos de 2 mensagens novas → aviso "Ainda não há o que compactar".
  - Disparos: `/compactar` ou `/compact` no composer; "Compactar conversa" no menu ⋯ (só com
    mensagens, desabilitado durante uma execução); paleta "Agzos IA: Compactar conversa".
  - Automática: `sendToChat` (chat e agente) e o botão **Continuar** estimam o histórico que
    iria ao modelo + a nova mensagem; acima do limite compactam antes e então enviam. Se o
    resumo falhar, avisa por toast e envia sem compactar; se o usuário parar durante a
    compactação, a mensagem volta para a fila (pausada).
  - Payload ao modelo (agente e chat) passa por `modelMessages`.
  - Mensagens anteriores ao último resumo ganham `.is-compacted` (esmaecidas; hover realça).
  - Marcador `.ai-compact-marker` com `<details>`: "Conversa compactada — N mensagens resumidas",
    expande para o resumo renderizado em Markdown sanitizado.
  - Fila: "Enviar agora" durante a compactação mantém o item na frente da fila (não interrompe
    o resumo); a fila anda quando a compactação/execução termina. Steer nunca compacta: a
    compactação só roda sem execução ativa.
- **`agent-ui.js`** — selo discreto `.ag-compacted` "Contexto compactado (−N caracteres de saídas
  antigas)" no ponto do turno em que o laço compactou.
- **Configurações → Agzos IA** — "Compactar Conversa Automaticamente" (checkbox) e "Limite para
  Compactar (tokens)" (8000–400000).
- **CSS** (`ai-panel.css`) — marcador, corpo do resumo, aviso de compactação, selo e esmaecido.

## Desvios e decisões

- **Resumo vai ao modelo como mensagem `user`** (prefixo "Resumo da conversa até aqui…"), não
  como `system`: alguns modelos locais rejeitam `system` fora da primeira posição; na Anthropic
  ele se junta à mensagem seguinte do usuário (alternância preservada).
- **Estimativa no renderer** conta o que de fato vai ao modelo: respostas do agente sem o
  marcador JSON (as saídas completas de ferramentas de turnos anteriores nunca são reenviadas,
  só o resumo legível das ações). Saídas de ferramenta contam de verdade no laço do agente (main).
  O contexto do editor (arquivo/seleção/terminal) não entra na estimativa: não é compactável e
  faria a compactação disparar a cada envio.
- **Compactação no laço respeita `autoCompact`**: desligado nas Configurações, o laço também não
  compacta.
- **Falha na compactação automática** não bloqueia o envio: toast com o erro e a mensagem segue
  sem compactar (nada se perde). Na manual, erro no painel.
- **`compactedCount`** = mensagens novas desde o último resumo (o resumo anterior entra no pedido
  de resumo, mas não na contagem).
